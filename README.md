# Tugas HTML Profile Biodata

Project ini dibuat berdasarkan instruksi tugas:
- Section 1: menu navigasi
- Section 2: judul di kiri dan gambar di kanan
- Section 3: biodata menggunakan HTML table dengan 6 informasi
- Section 4: portfolio
- Responsive untuk desktop dan mobile

## Struktur
- `index.html` - halaman utama
- `style.css` - styling halaman

## Cara menjalankan
1. Download/extract project.
2. Buka `index.html` menggunakan browser.
3. Untuk mengganti foto, ubah bagian `<img>` pada `index.html`.
4. Sesuaikan nama, email, domisili, skill, dan portfolio dengan data pribadi.

## Upload ke GitHub

Jalankan di folder project:

```bash
git init
git add .
git commit -m "Initial commit - tugas profile biodata"
git branch -M main
git remote add origin https://github.com/USERNAME/NAMA-REPOSITORY.git
git push -u origin main
```

Ganti `USERNAME/NAMA-REPOSITORY` dengan repository GitHub milik kamu.
